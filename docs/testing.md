# Testing

From the package directory, run:

```bash
composer test
composer lint
```

The feature suite covers credentials, registration, logout, resets, profile and password updates, social identity handling, passkeys, tokens, and Turnstile behavior. In the consuming application, test application-owned routes, response overrides, middleware, mail delivery, the configured guard, and external-provider callbacks.
